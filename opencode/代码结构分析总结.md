# OpenCode 代码结构分析总结

## 项目信息
- **项目名称**: StudioCMS (Web Sailor)
- **项目性质**: 全栈内容管理系统（CMS）
- **开发语言**: JavaScript (Node.js + 计划使用 Vue 3)
- **数据库**: MongoDB

## 核心架构

### 后端架构（已完成）
采用经典的 **MVC 分层架构**：

```
后端
├── Models (数据层)
│   ├── User.js - 用户模型（认证、资料、权限）
│   └── Role.js - 角色模型（权限集合）
│
├── Controllers (业务逻辑层)
│   ├── authController.js - 认证控制器（注册/登录/个人信息）
│   ├── userController.js - 用户管理（CRUD）
│   ├── roleController.js - 角色管理（CRUD）
│   ├── permissionController.js - 权限查询
│   └── uploadController.js - 文件上传
│
├── Routes (路由层)
│   ├── auth.js - 认证路由
│   ├── users.js - 用户管理路由
│   ├── roles.js - 角色管理路由
│   ├── permissions.js - 权限路由
│   └── upload.js - 上传路由
│
├── Middleware (中间件层)
│   └── auth.js - 认证和授权中间件
│       ├── protect - JWT认证
│       ├── authorize - 角色验证
│       ├── hasPermission - 权限验证
│       ├── isSuperAdmin - 超管验证
│       └── isAdmin - 管理员验证
│
└── Config (配置层)
    └── database.js - MongoDB连接配置
```

## 核心功能模块

### 1. 认证系统 ✅
- **用户注册**: 自动加密密码，分配默认权限
- **用户登录**: JWT Token生成（有效期30天）
- **密码加密**: bcryptjs + salt rounds 10
- **Token验证**: Bearer Token机制

### 2. 权限管理系统 ✅
**三级角色体系**:
```
super_admin (超级管理员)
    ↓
  admin (管理员)
    ↓
  user (普通用户)
```

**9种细粒度权限**:
- manage_articles - 管理文章
- manage_projects - 管理项目
- manage_members - 管理成员
- manage_users - 管理用户
- manage_roles - 管理角色
- manage_system - 系统管理
- view_analytics - 查看分析
- edit_profile - 编辑资料
- upload_avatar - 上传头像

### 3. 用户管理 ✅
- 查询所有用户（管理员）
- 创建新用户（管理员）
- 更新用户信息/权限（管理员）
- 删除用户（管理员）
- 更新个人资料（用户自己）
- 修改密码（用户自己）

### 4. 角色管理 ✅
- 自定义角色创建
- 角色权限配置
- 角色CRUD操作
- 权限继承机制

### 5. 文件上传 ✅
- **支持格式**: 图片（PNG/JPEG/GIF）、文档（PDF/DOC/DOCX）
- **大小限制**: 5MB
- **存储位置**: backend/uploads/
- **命名方式**: {timestamp}-{random}-{filename}
- **访问路径**: /uploads/{filename}

### 6. 待开发模块 ⏳
- 文章管理（articles）
- 项目管理（projects）
- 成员管理（members）
- 前端界面（Vue 3）

## API 接口设计

### 认证接口（Public）
```
POST /api/auth/register     # 注册
POST /api/auth/login        # 登录
GET  /api/auth/verify-token # 验证Token
```

### 用户接口（Protected）
```
GET  /api/auth/me           # 获取当前用户信息
PUT  /api/auth/profile      # 更新个人资料
PUT  /api/auth/password     # 修改密码
```

### 管理接口（Admin Only）
```
GET    /api/users           # 获取用户列表
POST   /api/users           # 创建用户
PUT    /api/users/:id       # 更新用户
DELETE /api/users/:id       # 删除用户

GET    /api/roles           # 获取角色列表
POST   /api/roles           # 创建角色
PUT    /api/roles/:id       # 更新角色
DELETE /api/roles/:id       # 删除角色

GET    /api/permissions     # 获取权限列表
```

### 文件接口（Authenticated）
```
POST /api/upload            # 上传文件
GET  /uploads/:filename     # 访问文件
```

## 安全特性

### 1. 认证安全
- ✅ JWT Token签名验证
- ✅ Token过期时间控制
- ✅ Bearer Token机制

### 2. 密码安全
- ✅ bcrypt加密（不可逆）
- ✅ Salt轮次：10
- ✅ 永不存储明文密码
- ✅ 密码查询自动排除

### 3. 接口安全
- ✅ Helmet安全头部
- ✅ CORS跨域配置
- ✅ Body大小限制（10MB）
- ✅ 分层权限验证

### 4. 文件安全
- ✅ 文件类型白名单
- ✅ 文件大小限制（5MB）
- ✅ 文件名随机化

### 5. 数据库安全
- ✅ Mongoose参数化查询（防SQL注入）
- ✅ 唯一索引约束
- ✅ 字段验证

## 数据库设计

### users 集合
```javascript
{
  username: String (unique),      // 用户名
  email: String (unique),         // 邮箱
  password: String (hashed),      // 密码哈希
  role: String,                   // 角色
  avatar: String,                 // 头像URL
  profile: {                      // 个人资料
    fullName, bio, skills,
    joinDate, phone, location
  },
  permissions: [String],          // 权限数组
  lastLogin: Date,                // 最后登录
  isActive: Boolean,              // 账户状态
  createdAt/updatedAt: Date       // 时间戳
}
```

### roles 集合
```javascript
{
  name: String (unique),          // 角色名
  description: String,            // 描述
  permissions: [String],          // 权限数组
  createdAt: Date                 // 创建时间
}
```
